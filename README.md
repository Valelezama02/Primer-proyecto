# upsleek

Landing page minimalista para la marca de dropshipping **upsleek**.

## Estructura

- `index.html` — contenido de la página (navegación, hero, beneficios, productos, newsletter, footer).
- `styles.css` — estilos y diseño responsive.

## Cómo verla

Abre `index.html` en tu navegador. No requiere instalación.

## Personalizar

- **Productos:** edita nombres y precios en la sección `#productos` de `index.html`.
- **Imágenes:** en `styles.css`, reemplaza los fondos `.product__img--1` … `--4` por
  `background: url('img/tu-producto.jpg') center/cover;`.
- **Colores:** cambia las variables en `:root` al inicio de `styles.css`.
