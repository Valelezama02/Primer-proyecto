# upsleek

Landing page minimalista para **upsleek**, tienda de dropshipping de productos de belleza y accesorios.

## Estructura

- `index.html` — contenido de la página (anuncio, navegación, hero, categorías, productos, beneficios, newsletter, footer).
- `styles.css` — estilos y diseño responsive.

## Cómo verla

Abre `index.html` en tu navegador. No requiere instalación.

## Personalizar

- **Productos:** edita nombres y precios en la sección `#productos` de `index.html`.
- **Imágenes:** en `styles.css`, reemplaza los fondos `.category--1` … `--4` y `.product__img--1` … `--4` por
  `background: url('img/tu-producto.jpg') center/cover;`.
- **Colores:** cambia las variables en `:root` al inicio de `styles.css`.
